## 补齐 CLI 依赖（2/3 成功）
- `ffmpeg`：choco 安装因权限失败（ProgramData 不可写）。改用 pip `imageio-ffmpeg`（清华镜像，装到系统 Python3.15），用其自带二进制 ffmpeg 9.0.2，复制到 `~/.workbuddy/bin/ffmpeg.exe`（该目录已在系统用户 PATH）。补齐 video-frames 缺失的 `scripts/frame.sh`（从 GitHub API base64 解码，raw 直连限流超时）。端到端抽帧测试成功。
- `summarize`：npm 包 `@steipete/summarize` 需 Node>=24，WorkBuddy 自带 Node22 不够。下载 Node 24.11.0 便携版到 `~/.workbuddy/bin/node24/`，用它全局安装包到 `node24/global/`，在 `~/.workbuddy/bin/summarize` 写 launcher 指向 `dist/cli.js`。免 Key 的 `--extract --plain` 模式验证通过（注意 CLI 自报版本 0.14.1，包版本 0.26.1，不影响功能）。完整总结模式仍需 API Key（GEMINI/OPENAI 等）。
- `nano-pdf`：确认无真实 CLI —— npm 上 `nano-pdf`/`@steipete/nano-pdf` 均 404，`steipete/nano-pdf` 仓库 404，只有技能说明无后端工具。无法补齐，属技能本身缺陷。
- 环境注意：Git Bash 会话 PATH 对 Windows 格式路径转换有坑，用 POSIX 格式 `/c/Users/...` 才生效；`~/.workbuddy/bin` 在系统用户 PATH 中，重启会话后 ffmpeg/summarize 可直接调用。
