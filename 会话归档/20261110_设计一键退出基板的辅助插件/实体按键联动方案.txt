一、一句话结论
------------------------------------------------------------
你现在的工具几乎不用改。F9 是「全局热键」——工具在后台、
哪怕被设备软件盖住，按 F9 它都收得到。所以所谓「实体按键」，
本质就是：买一个 USB 小设备，把它设成「按一下 = 按键盘 F9」。

  按按钮 → USB 设备发出 F9 → 工具收到 → 自动点完 4 步

成本几十到两三百元，不改设备、不改原厂软件、不碰 PLC。
唯一前提：工具 exe 要一直在电脑上运行（可设开机自启，见第六节）。


二、先零成本验证（今天就能做，别急着买）
------------------------------------------------------------
1. 让工具开着（面板被设备软件盖住也没关系）。
2. 直接按键盘上的 F9。
3. 若 4 步照常跑完 → 这条路通。买任何「能发 F9 的 USB 设备」
   都成立，往下看第三节采购。

若按 F9 时设备软件自己也有反应，说明 F9 被它占用了——
别硬上，跳到第七节「专用按键」，我给你改一个不冲突的键，
按钮也设成发那个键。这一步花一分钟，能省掉买错设备的钱。


三、四种硬件路线（按推荐排序）
------------------------------------------------------------
【路线 1 · 可编程宏键盘】推荐   ¥30~150
  1 键 / 3 键的小键盘，用卖家软件把其中一个键设成 F9。
  选「带板载记忆」的：设置存在键盘芯片里，换电脑不用重装，
  也不怕厂里管控软件拦设置程序。插 USB 被认成键盘，Win7 免驱。
  外观普通，适合按钮放在操作台、工人看惯键盘的场景。

【路线 2 · USB 大按钮盒】直观   ¥80~500
  蘑菇头急停样式的大按钮，戴手套也按得准，最醒目。
  必须问清能不能设成「键盘 F9」——有些大按钮是打印机/扫码
  模式，发的是别的内容，工具收不到。优先选带保护盖或钥匙孔的。

【路线 3 · USB 脚踏开关】双手忙时用   ¥50~200
  双手要拿载板时踩一脚即可。同样要能设成 F9。
  误踩风险最高，务必选带翻盖保护的，且安装在不易碰到处。

【路线 4 · 自制 Pico / Arduino 大按钮】¥30~80
  一个树莓派 Pico + 一个大按钮，编程成 USB 键盘发 F9。
  形态完全定制（可加指示灯、钥匙、双按钮），但要有人会焊和烧程序。

不推荐（别碰）：
  × 继电器直接短接键盘触点、改设备电路：破坏保修 + 安全风险
  × 让原厂在设备软件里加按钮：周期长、要停机，先把这条路跑通再说

—— 采购时复制这三句话问卖家 ——
  1. 「Win7 能免驱动用吗？插上是不是识别成 USB 键盘？」
  2. 「按键设置是存在设备里（板载记忆），还是要装电脑软件？」
     —— 一定要前者。
  3. 「能不能设成按一下只发一个 F9？能不能关掉长按连发？」
     —— 要单次触发。连按的事工具那边已经防住了（见第五节），
        但设备本身也别连发。


四、买到后怎么设置（照做即可）
------------------------------------------------------------
1. 插入 USB，等设备自动装好（ Win7 一般免驱）。
   Win7 可在「设备管理器 → 键盘」里看到多出一个 HID 键盘设备。
2. 用卖家的设置软件把那个键设成 F9，点「保存到设备 / 写入板载」，
   别只点「应用」——否则拔掉就丢。
3. 验证电脑确实收到了 F9：
   打开记事本，按一下按钮，屏幕上不应出现任何字符（F9 不打字）。
   更直接的验证：让工具开着，按按钮，看面板是否开始走步骤、
   日志是否新增一行。
4. 把按钮贴标签：「退出基板」，下面贴第五节那四条前提。
5. 拔掉设置软件（或收起来），日常不需要它，避免工人误改。


五、安全设计（取消确认框 + 培训低级工人，务必看）
------------------------------------------------------------
取消了确认框、又给低级工人一个大按钮，等于「一按设备就动」。
所以防护要从「弹窗确认」转移到「物理 + 管理」两层：

物理层
  · 按钮必须带保护盖、翻盖或钥匙开关，只有授权人能打开/插钥匙。
  · 放在不易误碰的位置；脚踏款一定要有翻盖，防止掉东西砸到。
  · 不要让按钮正对着通道或物料堆放区。

管理层
  · 按钮旁贴四条前提（和原来确认框里一样）：
      1) 设备无未清除报警
      2) 载板 / 当前批次无产品（空片或维护模式）
      3) 本次操作已获设备工程师批准
      4) 已确认当前 Heater 状态下允许执行
  · 新按钮/新工人上来，先勾「空跑」按几次，看日志对不对，
    再进维护模式空片实按，最后才谈正常生产。
  · 低级工人首试必须工程师在场。

工具侧已经具备的（不用你操心）
  · 连按防护：已改好。连按第二下只「嘀」一声，不会弹窗打断
    正在跑的步骤——按钮场景里这个很关键，已随本版 exe 更新。
  · Esc / 面板「中止」：执行中一直有效，工人发现不对能随时停。
  · 全程日志：每次触发、每一步点了什么窗口什么坐标都记下来，
    出事可追溯。


六、让工具开机就在后台（否则按按钮没反应）
------------------------------------------------------------
按钮只是发 F9，工具没开的话按了也没用。设成开机自启：

1. 先把 exe 固定放一个位置，例如
   C:\Tools\一键退出\OneKeyUnload_Win7.exe
   不要放 U 盘 / 桌面临时文件夹；必须是可写目录，
   因为 calib.ini（坐标）和日志要写在 exe 同目录。
2. 按 Win + R，输入 shell:startup 回车，打开「启动」文件夹。
3. 右键 exe → 创建快捷方式，把快捷方式拖进「启动」文件夹。
4. 重启一次验证：开机后工具面板应自动出现，按按钮即触发。
5. 把面板拖到屏幕角落、别挡住设备软件即可。
   现场坐标取点仍用 F12，取完存在同目录 calib.ini，重启不丢。

注意：换电脑或重装系统后，calib.ini 要一起拷过去，否则要重取点。


七、可选升级（需要我再改一次脚本 + 重编 exe）
------------------------------------------------------------
以上方案用现有 exe 就能落地。下面几项是我可以再帮你做的，
按「值得做」排序，你要哪个说一声：

A. 专用按键（推荐做，防误触最好）
   现在认 F9，工人在键盘上误按 F9 也会触发，设备软件也可能占用。
   可改成认一个专用组合键（如 Ctrl+Alt+F9，键帽上根本按不出来），
   按钮设成发同一个组合键。好处：
     · 键盘误按、别的软件热键都不会触发
     · 日志能区分「键盘 F9」和「实体按钮」，便于统计追溯
   改完给你新的 exe，替换即可，坐标不用重取。

B. 开机静默启动 + 托盘常驻
   做成开机后不显示大面板、缩到右下角托盘，只留按钮操作，
   界面更干净、更像一个「设备」。需要时双击托盘图标才展开。

C. 声光反馈
   执行开始 / 结束 / 中止给三种不同蜂鸣，或带一个状态灯，
   工人不用盯屏幕就知道成没成功。

D. 触发计数
   日志里统计当天按了几次、每次谁当班（可加简单班次选择），
   交接班核对，方便管理和追责。

E. 双按钮确认（双手）
   两个按钮分开放，必须 2 秒内先后按下才执行，
   防单人误碰。适合风险更高的工序。


八、给低级工人的一页纸 SOP（可打印贴在按钮旁）
------------------------------------------------------------
        【 退出基板 · 一键操作 】

   按之前先看一眼：
     □ 没有报警      □ 板子是空的
     □ 工程师已同意  □ 加热状态已确认

   1) 打开按钮保护盖
   2) 按一下按钮，手离开
   3) 看屏幕走到「执行结束」→ 取板
   4) 合上保护盖

   不对劲就按 Esc 或点面板「中止」，然后叫工程师。

   禁止：连按 / 长按不放 / 带产品时按 / 私自拆保护盖


九、待你确认的 4 件事
------------------------------------------------------------
1. 用哪种硬件？（宏键盘 / 大按钮盒 / 脚踏 / 先零成本验证）
2. 要不要第七节的 A「专用按键」？我建议要，防误触最好。
3. 按钮装在设备哪一侧、离电脑多远？——决定 USB 线长度，
   线不够长可用 USB 延长线，别用无线（延迟和断连风险）。
4. 厂里 IT 是否允许插 USB 键盘类外设？
   之前批的是绿色 exe，外设最好也问一声，一次说清省得返工。
